## Data Sources

- List of Models
    - Nothing to download
    - Data provided in `model_lists/hugging_face_models.csv`

- FLORES-200
    - Download original version from https://github.com/facebookresearch/flores/blob/main/flores200/README.md
    - Place data in `flores200_dataset` folder

- LinguaMeta
    - Download `linguameta.tsv` from https://github.com/google-research/url-nlp/tree/main/linguameta
    - Place data in `linguameta` folder
    
- Common Crawl
    - Download `languages.csv` from https://commoncrawl.github.io/cc-crawl-statistics/plots/languages
    - Place data in `commoncrawl` folder
    
- ISO 639-3
    - Download ISO 639-3 macrolanguage mappings from https://iso639-3.sil.org/code_tables/download_tables
    - Place data in `iso_639_3` folder
